# CompatBIM

Sistema SaaS de gestão e compatibilização de projetos BIM para escritórios de arquitetura e engenharia.

## Recursos

- 🏢 Multi-tenant (cada escritório com seus dados)
- 👥 4 perfis: Admin, Coordenador, Projetista, Gerente
- 📋 Apontamentos (issues BIM) com workflow completo
- ✅ Tarefas com checklist, anexos, vínculo a apontamentos
- ⏱️ Timer integrado nas tarefas
- 💬 Chat geral do escritório + chat por projeto
- 📊 Visão geral com KPIs por perfil
- 🔔 Notificações de prazo

## Como rodar localmente

```bash
npm install
npm run dev
```

## Tecnologias

- React 18
- Vite
- Lucide Icons
- Recharts
